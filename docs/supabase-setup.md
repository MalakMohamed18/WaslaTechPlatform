# Supabase Configuration & Local Setup Guide

## 1. Environment Variables Setup
To run the project locally, create a `.env` file in the root directory of the project and add the following variables:

```env
VITE_APP_TITLE=Wasla Tech Platform
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
